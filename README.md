# Road Condition and Accident Severity Prediction using Machine Learning

##  Project Overview

This project applies machine learning techniques to predict accident severity using the Indian Road Accident Dataset. The goal is to analyze patterns and evaluate different models for classification.

##  Dataset

* Source: https://www.kaggle.com/datasets/sehaj1104/indian-road-accident-dataset-20222025
* Rows: 20,000
* Columns: 24

## Task

Classification (Multi-class)
Target Variable: Accident Severity

## Models Used

* Logistic Regression
* Decision Tree
* k-Nearest Neighbors (k-NN)
* Random Forest
* Support Vector Machine (SVM)
* XGBoost

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC

##  How to Run

1. Download the dataset from the link above
2. Upload dataset to Kaggle / local environment
3. Update dataset path in notebooks
4. Run notebooks (RQ1 → RQ7)
